# Upstream

[Upstream](https://upstream-wca.app) is a flexible tool designed to support fish passage planning in Western Washington.

# Release Notes

## Upstream WCA 1.0 
Released on 01/24/2024

## Upstream WCA 1.1 
Released on 07/24/2024
- Faster load times
- Satellite and topographic base map options 
- Current stream temperatures now from [NorWeST](https://www.fs.usda.gov/rm/boise/AWAE/projects/NorWeST.html) (Explore; Suggest)
- Future [NorWeST](https://www.fs.usda.gov/rm/boise/AWAE/projects/NorWeST.html) stream temperature predictions for years 2040 and 2080 (Explore) 

## Upstream WCA 1.2 
Released on 01/22/2025
- Improved culvert to stream matching procedure
- Welcome map includes culverts determined to be upstream of non-culvert barriers

## Upstream WCA 1.3
Released on 09/04/2026
- Updated barrier inventory, habitat, and cost data
- Corrected habitat estimates on braided streams and side channels, returning 1,321 culverts and 26,582 km of habitat that were previously excluded
- Project cost predictions now combine WSDOT engineering estimates, where available, with modeled costs
- Habitat volume now reported in cubic meters (Explore; Suggest; Custom)
- Looking up a barrier by ID now highlights it in place, keeping surrounding barriers visible for context (Explore)
- Providing your own project cost now adjusts modeled costs only, leaving WSDOT engineering estimates unchanged (Suggest; Custom)
- Fixed: "All"/"None" defaults could stay selected alongside a specific choice, so subarea and species filters had no effect (Suggest; Custom)
- Fixed: the map could go blank on some custom plans (Custom)
- Fixed: the click tool now works for categorical variables (Explore)
- New default base map
